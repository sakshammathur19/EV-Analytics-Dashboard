⚡ EV Sales Analytics Dashboard

An interactive Power BI dashboard built to analyze Electric Vehicle (EV) sales performance, market trends, vehicle segments, and business KPIs through interactive visualizations.

📊 Project Overview

This project transforms EV sales data into an interactive business intelligence dashboard using Microsoft Power BI.

The dashboard helps users understand sales performance, identify trends, compare vehicle categories, and explore the data using dynamic filters and slicers.

🎯 Objectives

Analyze overall EV sales performance

Track important business KPIs

Identify sales trends over time

Compare vehicle categories and models

Analyze regional and market performance

Create an interactive and user-friendly reporting experience

Present data-driven insights for business decision-making

🛠️ Technologies Used

Power BI – Dashboard development and data visualization

DAX – Calculated measures and KPIs

Power Query – Data cleaning and transformation

Data Modeling – Building relationships for analysis

📌 Dashboard Features

Interactive KPI cards

Sales trend analysis

Vehicle/model performance analysis

Category-wise comparisons

Interactive slicers and filters

Date-based analysis

Dynamic visualizations

Business-focused dashboard layout

📈 Key KPIs

The dashboard provides metrics such as:

Total EV Sales

Total Vehicles

Average Sales

Sales by Category

Sales by Model

Sales Trends

Regional/Market Performance

🚀 How to Use

Download the .pbix file from the PowerBI folder.

Open it using Microsoft Power BI Desktop.

If required, update the data source path.

Refresh the dataset.

Use the available slicers and filters to explore the dashboard.

🔍 Business Insights

The dashboard can be used to:

Monitor EV sales performance

Discover high-performing vehicle segments

Compare models and categories

Identify changes in sales over time

Understand market-level performance

Support data-driven business decisions
